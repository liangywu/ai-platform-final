電商智慧客服與評價分析系統

專案主題：基於本地大語言模型的智慧客服自動化與評價分析解決方案

1. 專案介紹 (做了什麼)

本專案在 WSL2 環境下使用 Python (`uv`) 呼叫本地 Ollama (`qwen2.5` 與 `nomic-embed-text`)，打造一個具備商業實務應用的電商智慧客服系統，涵蓋四大核心模組：

  • 串流輸出 (Streaming): 模擬智慧客服即時打字回覆顧客的退換貨等諮詢。
  • 結構化輸出 (Structured Output): 自動分析顧客評論，將滿意度、問題分類與處理優先級提取為標準 JSON 格式。
  • 工具呼叫 (Tool Calling): 整合客服後台的折扣計算工具，精確計算優惠價格並由 AI 回應。
  • Embedding 嵌入向量: 進行 FAQ 知識庫與顧客提問的語意相似度檢索準備。

2. 執行步驟 (怎麼執行)

# 1. 確保 Ollama 服務已啟動並下載模型
ollama run qwen2.5
ollama run nomic-embed-text

# 2. 透過 uv 在終端機執行主程式
uv run main.py

3. 執行結果

程式能流暢地運行四大情境：終端機即時印出客服逐字回覆串流、完美解析出顧客評價的 JSON 結構、自動運算折扣金額，以及成功產生 FAQ 嵌入向量特徵，完全符合電商自動化客服的需求。

4. AI 使用說明與環境

開發過程中運用 Ollama 本地模型進行提示詞工程與格式約束，未涉及任何雲端 API 金鑰（符合 `.env` 資安規範）。並透過附帶的 Dockerfile 進行容器化封裝，確保跨環境的一致性與可攜性。
