AI 小專案成果報告

1. 專案介紹 (做了什麼)

本專案使用 Python (`uv`) 呼叫本地 Ollama (`qwen2.5` 與 `nomic-embed-text`)，在 WSL2 環境下完整實作了四種核心 AI 能力：

  • 串流輸出 (Streaming): 即時逐字生成回應。
  • 結構化輸出 (Structured Output): 強制模型輸出指定 JSON Schema 格式。
  • 工具呼叫 (Tool Calling): 讓 AI 自主識別並呼叫自定義 Python 函式。
  • Embedding 嵌入向量: 將文字轉換為高維度向量特徵。

2. 執行步驟 (怎麼執行)

# 確保 Ollama 服務已啟動並下載對應模型
ollama run qwen2.5

# 透過 uv 執行主程式
uv run main.py

3. 執行結果

程式能正確執行並依序展示四大功能：終端機能順利輸出串流文字、將評論解析為標準 JSON、自動運算數學工具函數，以及成功產出嵌入向量長度與數值。

4. AI 使用說明與環境

開發過程中使用系統提示詞引導 Ollama 進行邏輯與格式控制，並透過 Dockerfile 進行容器化封裝，確保環境一致性。
